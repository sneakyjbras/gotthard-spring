  kubectl -n {{ .Release.Namespace }} apply -f secrets/secret.yaml   # your filled-in copy, gitignored

{{- if not .Values.imagePullSecrets }}

NOTE — this repository is private, so ghcr.io/sneakyjbras/gotthard-{backend,frontend,docs}
are private packages by default. No imagePullSecrets are configured (see
values.yaml), so pulling them here needs one of:
  - make the three packages public on GHCR (Package settings -> Change visibility) —
    this is the intended, credential-free demo path, or
  - create a pull secret and set imagePullSecrets in values.yaml:
      kubectl -n {{ .Release.Namespace }} create secret docker-registry ghcr-pull \
        --docker-server=ghcr.io --docker-username=<user> --docker-password=<PAT with read:packages>
{{- end }}

  open http://localhost:8080

Docs site:

  open http://localhost:8081

Watch the rollout:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

ANTHROPIC_API_KEY is optional. Absent from the Secret, the backend logs which
AI adapter is live and runs the offline stub adapter — the intended reviewer
path (see ch.gotthard.ai.analysis.LlmClientConfiguration). Add the key to
secrets/secret.yaml and `helm upgrade` to switch it to the real Claude adapter.
