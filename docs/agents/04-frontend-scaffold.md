# Agent 04 — Frontend scaffold and design system

**Model:** Claude Sonnet 5 · **Wave:** 1 · **Scope:** `frontend/**`

Sonnet because the aesthetic decisions were already made and written down; this agent
implements a specified design system rather than inventing one.

## Instructions given

> Vite + React + TypeScript + Tailwind. No component library — MUI and shadcn were both
> rejected deliberately. Swiss International style: strict grid, hairline rules, generous
> whitespace, one accent colour used sparingly, no rounded corners, no shadows. Every
> number, ID, IBAN and hash renders in tabular monospace so columns align. Define the
> design tokens as CSS custom properties first, light and dark, and build everything on
> them.
